# OtterHub 个人部署与使用手册（小白版）

> 本文档整理自完整部署与使用交流记录，方便以后自己查阅，或直接发给其他 AI 继续协助配置。

---

## 一、项目简介

**OtterHub** 是一个基于 **Cloudflare Pages + KV + Telegram Bot API** 的免费私人云盘。

- 真实文件存储在你自己的 **Telegram 频道** 中
- 文件元数据（名字、大小、位置等）存储在你自己的 **Cloudflare KV** 中
- 网站运行在你自己的 **Cloudflare Pages** 上
- 完全自托管，作者无法访问你的任何数据

**核心特点：**
- 支持图片、音频、视频、文档
- 网页端支持分片上传，实测可稳定上传约 100MB 文件（理论最大约 1GB）
- 支持 HTTP Range（视频可边下边播）
- 密码登录保护
- 可选 NSFW 图片本地检测 + 安全模式遮罩
- 支持从绑定的 Telegram 频道/群直接发 ≤20MB 文件自动收录

---

## 二、隐私与安全说明（重要）

1. **作者看不到你的文件**  
   所有数据都在你自己的 Cloudflare 账号和 Telegram 频道里，作者没有任何访问权限。

2. **只有你能管理文件**  
   需要输入你自己设置的网站密码才能登录。

3. **NSFW 检测方式**  
   使用浏览器本地运行的 nsfw.js 库进行检测，图片不会上传到任何外部服务器。开启安全模式后，检测到的 NSFW 图片会自动遮罩。

4. **上传不依赖 Telegram 登录**  
   你不需要在浏览器登录 Telegram。随便一台设备，只要打开你的网站并输入密码，就能上传、下载、管理文件。

---

## 三、网络环境说明（大陆用户重点关注）

- 网站本身通过 Cloudflare，一般可以正常打开。
- 实际上传/下载文件时，是 **Cloudflare 服务器** 去连接 Telegram API。
- 因为请求从 Cloudflare 全球节点发出，通常比在大陆直接访问 Telegram 更顺畅，但**不能 100% 保证永远稳定**。
- 网络波动时可能出现上传失败或下载卡住的情况，这是所有「Cloudflare + Telegram」方案的共同限制。

**建议：** 重要文件不要只存这一份，可额外备份。

## 五、完整部署步骤

### 1. 创建 Telegram Bot 并获取 Token

1. 打开 Telegram，搜索 `@BotFather`
2. 发送 `/newbot`
3. 按提示设置名称和用户名（用户名必须以 `bot` 结尾）
4. 复制并保存返回的 **Token**（格式类似 `1234567890:AAHxxxx...`）

### 2. 创建用于存储的频道

1. Telegram 新建一个**私有频道**
2. 把刚创建的 Bot 添加为管理员
3. 权限至少勾选：发布消息、编辑消息、删除消息

### 3. 获取频道 Chat ID

1. 在频道里随便发一条消息
2. 浏览器打开：
   ```
   https://api.telegram.org/bot你的Token/getUpdates
   ```
3. 搜索 `"id":-100`，找到类似 `-1001234567890` 的数字，这就是 **Chat ID**（必须带负号）

### 4. Fork 项目

1. 打开 https://github.com/DJChanahCJD/OtterHub
2. 点击右上角 **Fork**

### 5. 在 Cloudflare 创建 Pages 项目

1. 登录 Cloudflare Dashboard → Workers 和 Pages → 创建 → Pages → 连接到 Git
2. 选择你 Fork 的 OtterHub 仓库
3. 构建设置：
   - 构建命令：`npm install && npm run build`
   - 构建输出目录：`frontend/out`
4. 保存并部署（第一次可能失败，先继续下一步）

### 6. 创建并绑定 KV

1. Cloudflare → Workers 和 Pages → KV → 创建命名空间，名称填：`oh_file_url`
2. 回到你的 Pages 项目 → 设置 → 函数 → KV 命名空间绑定
3. 添加绑定：
   - 变量名：`oh_file_url`
   - 选择刚创建的命名空间

### 7. 添加环境变量

在 Pages 项目 → 设置 → 环境变量 中添加（生产环境）：

| 变量名                | 类型     | 是否必填 | 说明与建议值 |
|-----------------------|----------|----------|--------------|
| `PASSWORD`            | 密钥     | 必填     | 网站登录密码 |
| `TG_BOT_TOKEN`        | 密钥     | 必填     | Bot Token |
| `TG_CHAT_ID`          | 文本/密钥| 必填     | `-100` 开头的频道 ID |
| `API_TOKEN`           | 密钥     | 可选     | 随便一串字符（给 API 调用用） |
| `TG_WEBHOOK_SECRET`   | 密钥     | 可选     | 一串随机字符（开启频道自动收录时需要） |

**说明：**
- `TG_CHAT_ID` 就是 `-100` 开头的那个数字。
- `API_TOKEN`：现在不用 API 可以随便填或先不填。
- `TG_WEBHOOK_SECRET`：想用「频道直接发文件自动收录」功能时再认真设置。

添加完成后，回到部署页面点击「重试部署」。

### 8. 首次登录测试

打开你的 `xxx.pages.dev` 域名，输入 `PASSWORD` 登录，尝试上传一个小文件测试。

## 六、上传文件的方式

| 方式                     | 是否进入 OtterHub | 限制          | 说明 |
|--------------------------|-------------------|---------------|------|
| 网页上传                 | 是                | 支持大文件分片 | 最推荐、最稳定 |
| 在绑定的频道/群发文件    | 是（需配置 Webhook） | ≤20MB       | 方便手机使用 |
| 私聊发给 Bot             | 否                | -             | 目前不支持自动收录 |

**开启频道自动收录：**
1. 确保已设置 `TG_WEBHOOK_SECRET`
2. 网站登录后进入设置 → 常规设置 → 上传设置
3. 点击「配置 Webhook」，再点「检查状态」确认成功

## 七、关于界面语言

OtterHub 目前没有内置中文界面（作者 README 是中英双语，但网页本身是英文）。

**推荐做法：**  
使用 Chrome / Edge 浏览器右键页面 → 「翻译成中文」。对文件管理界面翻译效果通常够用。

## 八、是否可以断开 Git 连接

可以，而且建议断开。

**断开后的影响：**
- 优点：原作者更新代码不会自动影响你的网站，更稳定。
- 缺点：以后想改代码需要手动重新部署。

操作路径：Pages 项目 → 设置 → 构建与部署 / 源代码 → 断开连接。

断开不影响已配置的环境变量和 KV，网站继续正常运行。

## 九、常见问题快速参考

**Q：上传后文件暂时不完整？**  
A：大文件使用异步上传，稍等片刻刷新页面即可。

**Q：大陆网络上传失败？**  
A：属于正常现象，可多试几次，或重要文件额外备份。

**Q：私聊 Bot 发文件没反应？**  
A：正常，目前只支持频道/群消息自动收录。

**Q：想换密码或 Token？**  
A：在环境变量里修改对应值，然后重新部署一次。
